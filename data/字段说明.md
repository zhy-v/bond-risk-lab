# 输入输出字段与数据来源

所有预设由项目构造，非真实证券报价，不涉及隐私。单位换算在模型入口完成，网页中的百分数除以100后进入引擎；bp除以10000。

| 字段 | 含义 | 单位或约定 |
|---|---|---|
| face | 每张债券到期偿还面值 | 元，正值 |
| coupon | 票面年利率 | 小数，如0.02 |
| yield | 名义年化YTM | 小数，按freq复利 |
| years | 买入时剩余期限 | 整年，1至50 |
| freq | 每年付息次数 | 1、2或4 |
| shockBp | 收益率平行变化 | bp；100表示加1个百分点 |
| holdingYears | 持有期 | 整年，不超过years |
| reinvest | 票息是否再投资 | 布尔值；利率为冲击后YTM |
| price | 买入或情景价格 | 元/张 |
| macaulay / modified | 麦考利/修正久期 | 年 |
| convexity | 现金流价格二阶敏感度 | 年的平方 |
| dv01 | 利率加1bp的价格损失近似 | 元/张 |
| total / annual | 持有期总回报/有效年化 | 小数 |
| errorLinear / errorQuadratic | 近似减精确价格变化率 | 价格变化率的bp |

现金流时间为k/freq年，末期包含本金；持有期末出售为付息后价格，到期本金只计入一次。

教材核验：第十二章课件例12-3，面值1000、票息10%、期限2年、市场YTM12%、半年付息，价格约965.35。此样例为教材来源，其他预设为项目构造。处理过程和计算实现均在dist/engine.js中。
